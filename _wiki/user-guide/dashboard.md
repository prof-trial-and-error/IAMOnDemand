## Dashboard Overview

The IAM OnDemand dashboard is your central hub for managing all aspects of your managed Keycloak instances. This guide will help you understand the key features and navigation.

## Main Dashboard Areas

### Instance Overview

The main dashboard displays all your Keycloak instances at a glance:

- **Status Indicator** - Green (healthy), Yellow (warning), Red (issues)
- **Instance Name** - Your custom name for each instance
- **Region** - Data center location
- **Plan Tier** - Starter, Professional, or Enterprise
- **Quick Actions** - Open Admin Console, View Metrics, Settings

### Navigation Menu

The left sidebar provides access to all dashboard sections:

- **Instances** - List and manage your Keycloak instances
- **Billing** - View invoices and manage payment methods
- **Team** - Invite team members and manage permissions
- **Settings** - Account settings and preferences
- **Support** - Access documentation and contact support

## Instance Management

### Creating a New Instance

1. Click **New Instance** button
2. Select your plan tier
3. Choose deployment region
4. Configure instance name
5. Review and confirm

### Instance Details

Click on any instance to view detailed information:

- Connection details and endpoints
- Current resource usage
- Recent activity logs
- Backup status

## Quick Actions

### Open Admin Console

Direct access to the Keycloak admin console for your instance.

### View Metrics

Real-time and historical metrics including:

- Active sessions
- Authentication requests
- Error rates
- Response times

### Manage Backups

- View backup history
- Trigger manual backup
- Restore from backup
